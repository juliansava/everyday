# Everyday Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Everyday, an installable offline web app for an Android phone that schedules and guides a daily morning mobility routine, three kettlebell sessions and two spinning sessions per week, records reps and live chest-strap heart rate, and shows progress.

**Architecture:** A Preact + TypeScript single-page app built with Vite and installed as a PWA. Pure logic modules (program, engine, progress, hr parsing) hold all rules and are unit-tested with Vitest. Thin browser adapters (IndexedDB via `idb`, Web Bluetooth, Web Speech, Web Audio, Wake Lock) wrap device APIs, and `ui/` wires everything into screens. Data never leaves the phone except as a user-exported backup file.

**Tech Stack:** TypeScript 5, Preact 10, Vite 5, `@preact/preset-vite`, `vite-plugin-pwa`, `idb` 8, Vitest 2, `fake-indexeddb` (tests), `@vite-pwa/assets-generator` (icons), GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-23-everyday-design.md`

## Global Constraints

- Target: Chrome on Android, installed to the home screen. Must work fully offline after the first load.
- No server, no accounts. All user data lives in IndexedDB on the phone; the only way out is the backup file.
- Runtime dependencies: `preact` and `idb` only.
- Hosted at `https://<github-user>.github.io/everyday/`, so Vite `base` is `/everyday/`.
- Dates are local calendar dates as `YYYY-MM-DD` strings. Weekday index `0` = Monday … `6` = Sunday. The week runs Monday to Sunday.
- Default max HR: **193**. Zone 2 = `round(0.60 × max)`–`round(0.70 × max)` → 116–135. Zone 5 target = `round(0.90 × max)`–`round(0.95 × max)` → 174–183.
- Bells owned by default: 8, 12, 16 kg.
- Morning routine: exactly 300 s of exercises, plus a 5 s get-ready.
- Zone 2 ride: 5 min easy + main block + 5 min cool-down. Main block starts at 45 min, grows by 5 min, caps at 60 min.
- Zone 5 ride: 10 min warm-up + 4 × (4 min hard + 3 min easy, no easy after the 4th) + 5 min cool-down = 40 min.
- Kettlebell: 2 warm-up rounds, 60 s "Get your bells", 3 circuit rounds. Rest between rounds 90 / 75 / 60 s, default 90.
- UI copy: English, sentence case, no exclamation marks.
- Theme follows the system light/dark setting.
- Node 20 or newer.

## Refinements to the spec

These came up while planning and are deliberate:

1. **No `accepted` store.** A progression suggestion is accepted on the kettlebell start screen and applies to the session being started, so the session's own sets record it. The current ladder step is derived from the latest session.
2. **`SessionRecord.stepIndex`** is added so an interrupted session can resume from the right step.
3. **`SetRecord.plannedRepsPerSide`** is added so "did all planned reps" can be checked later.
4. **`SessionRecord.params.maxHr`** is stored for rides so metrics can be recomputed with the zones that were used.
5. **Pure session helpers** (create, complete, resume, rebuild routine) live in `src/progress/session.ts`.
6. **Dev-only URL switches**: `?fakehr` uses a simulated strap, `?speed=N` runs workout clocks N× faster, `?start=kb|z2|z5` jumps into a training, `?gallery` shows all drawings. They exist only to test on a desktop and are harmless in production.
7. **Start screens for both trainings.** A kettlebell or spin session is only created when Start is tapped on its start screen, so backing out leaves nothing half-recorded.

```ts
  | 'lymphatic-hops'
  | 'trunk-twists'

  | 'deep-squat-hold'

  | 'single-arm-swing'
  | 'clean-and-press'
  | 'low-windmill'
  | 'overhead-windmill'
  | 'renegade-row-push-up';

export interface Exercise {
  id: ExerciseId;
  name: string;
  /** One-line form cue shown under the exercise name. */
  cue: string;
  /** Reps are counted per side. */
  perSide: boolean;
}

export type SessionKind = 'morning' | 'kb' | 'z2' | 'z5';
export type TrainingKind = Exclude<SessionKind, 'morning'>;

/** 0 = Monday … 6 = Sunday. */
export type Weekday = 0 | 1 | 2 | 3 | 4 | 5 | 6;

export interface Range {
  low: number;
  high: number;
}

/** Something to say `at` seconds after a step starts. */
export interface Cue {
  at: number;
  say: string;
}

export type SpinPhase = 'warmup' | 'main' | 'hard' | 'easy' | 'cooldown';

/** A step that ends by itself after `durationSec`. */
export interface TimedStep {
  kind: 'timed';
  /** Unique within its routine. */
  id: string;
  title: string;
  detail?: string;
  /** Drives the drawing. Absent for rests and spin phases. */
  exerciseId?: ExerciseId;
  durationSec: number;
  cues: Cue[];
  /** Spin only. */
  phase?: SpinPhase;
  /** Spin only: bpm target during this step, `null` for no target. */
  target?: Range | null;
}

export interface TapItem {
  exerciseId: ExerciseId;
  /** Per side when the exercise is per side. */
  reps: number;
}

/** A step that ends when the user taps Done. */
export interface TapStep {
  kind: 'tap';
  id: string;
  title: string;
  block: 'warmup' | 'circuit';
  /** 1-based. */
  round: number;
  /** Warm-up rounds list 3 items; circuit steps list 1. */
  items: TapItem[];
  /** Circuit only; `null` in the warm-up. */
  weightKg: number | null;
}

export type Step = TimedStep | TapStep;
```

```ts
import type { Range } from './types';

export const DEFAULT_MAX_HR = 193;

export function zone2(maxHr: number): Range {
  return { low: Math.round(maxHr * 0.6), high: Math.round(maxHr * 0.7) };
}

export function zone5(maxHr: number): Range {
  return { low: Math.round(maxHr * 0.9), high: Math.round(maxHr * 0.95) };
}

export type ZonePosition = 'below' | 'in' | 'above';

export function positionIn(bpm: number, range: Range): ZonePosition {
  if (bpm < range.low) return 'below';
  if (bpm > range.high) return 'above';
  return 'in';
}
```

```ts
import type { SessionKind, TrainingKind, Weekday } from './types';

export type TrainingDays = Record<Weekday, TrainingKind | null>;

export const DEFAULT_TRAINING_DAYS: TrainingDays = {
  0: 'kb',
  1: 'z2',
  2: 'kb',
  3: 'z5',
  4: 'kb',
  5: null,
  6: null,
};

const DAY_MS = 86_400_000;

// Date strings are calendar dates; doing the arithmetic in UTC avoids DST shifts.
function toUtcMs(date: string): number {
  const [y, m, d] = date.split('-').map(Number);
  return Date.UTC(y, m - 1, d);
}

function fromUtcMs(ms: number): string {
  return new Date(ms).toISOString().slice(0, 10);
}

export function todayISO(now: Date = new Date()): string {
  const y = now.getFullYear();
  const m = String(now.getMonth() + 1).padStart(2, '0');
  const d = String(now.getDate()).padStart(2, '0');
  return `${y}-${m}-${d}`;
}

export function addDays(date: string, n: number): string {
  return fromUtcMs(toUtcMs(date) + n * DAY_MS);
}

export function daysBetween(a: string, b: string): number {
  return Math.round((toUtcMs(b) - toUtcMs(a)) / DAY_MS);
}

export function weekdayOf(date: string): Weekday {
  return ((new Date(toUtcMs(date)).getUTCDay() + 6) % 7) as Weekday;
}

export function weekStart(date: string): string {
  return addDays(date, -weekdayOf(date));
}

export function weekDates(date: string): string[] {
  const monday = weekStart(date);
  return Array.from({ length: 7 }, (_, i) => addDays(monday, i));
}

export function trainingFor(date: string, days: TrainingDays): TrainingKind | null {
  return days[weekdayOf(date)];
}

export function plannedFor(date: string, days: TrainingDays): SessionKind[] {
  const training = trainingFor(date, days);
  return training ? ['morning', training] : ['morning'];
}
```

```ts
  id: ExerciseId;
  sec: number;
  detail: string;
  switchAt?: number;
}

const MORNING: MorningItem[] = [
  { id: 'lymphatic-hops', sec: 40, detail: EXERCISES['lymphatic-hops'].cue },

function breathCues(sec: number): Cue[] {
  const cues: Cue[] = [];
  for (let t = 0; t < sec; t += 10) {
    if (t > 0) cues.push({ at: t, say: 'In' });
    cues.push({ at: t + 4, say: 'Out' });
  }
  return cues;
```

```ts
import type { Step } from '../program/types';

export type RunnerEvent =
  | { type: 'step'; index: number; step: Step }
  | { type: 'say'; text: string }
  | { type: 'beep'; remaining: number }
  | { type: 'finished' };

/** Cues more than this many seconds late are dropped (e.g. after the phone slept). */
export const STALE_SEC = 2;

/**
 * Runs a list of steps. All timing is derived from `now()` against the step's
 * start time, so a throttled interval or a brief screen lock never makes the
 * countdown drift: the next `tick()` simply catches up.
 */
export class Runner {
  private index: number;
  private stepStart: number;
  private readonly startedAt: number;
  private pausedAt: number | null = null;
  private pausedTotal = 0;
  private lastElapsed = -1;
  private ended = false;

  constructor(
    readonly steps: Step[],
    private readonly now: () => number = Date.now,
    startIndex = 0,
  ) {
    this.startedAt = now();
    this.stepStart = this.startedAt;
    this.index = startIndex;
  }

  get stepIndex(): number {
    return this.index;
  }

  get finished(): boolean {
    return this.ended;
  }

  get paused(): boolean {
    return this.pausedAt !== null;
  }

  current(): Step | undefined {
    return this.steps[this.index];
  }

  /** Seconds into the current step, excluding pauses. */
  elapsedInStep(): number {
    return Math.max(0, (this.clock() - this.stepStart) / 1000);
  }

  remainingInStep(): number {
    const step = this.current();
    return step?.kind === 'timed' ? Math.max(0, step.durationSec - this.elapsedInStep()) : 0;
  }

  /** Seconds since the runner was created, excluding pauses. */
  totalElapsed(): number {
    return Math.max(0, (this.clock() - this.startedAt - this.pausedTotal) / 1000);
  }

  start(): RunnerEvent[] {
    return this.enter(this.index, this.now());
  }

  tick(): RunnerEvent[] {
    if (this.ended || this.paused) return [];
    let events: RunnerEvent[] | null = null;
    let step = this.current();
    while (step?.kind === 'timed' && this.elapsedInStep() >= step.durationSec) {
      // The next step starts exactly when this one ended, not when we noticed.
      events = this.enter(this.index + 1, this.stepStart + step.durationSec * 1000);
      step = this.current();
    }
    if (events) return events;
    return step ? this.dueCues(step) : [];
  }

  /** Completes the current step: Done on a tap step, Skip on a timed one. */
  done(): RunnerEvent[] {
    if (this.ended || this.paused) return [];
    return this.enter(this.index + 1, this.now());
  }

  back(): RunnerEvent[] {
    if (this.paused) return [];
    this.ended = false;
    return this.enter(Math.max(0, this.index - 1), this.now());
  }

  pause(): void {
    if (!this.paused && !this.ended) this.pausedAt = this.now();
  }

  resume(): void {
    if (this.pausedAt === null) return;
    const pausedFor = this.now() - this.pausedAt;
    this.stepStart += pausedFor;
    this.pausedTotal += pausedFor;
    this.pausedAt = null;
  }

  private clock(): number {
    return this.pausedAt ?? this.now();
  }

  private enter(index: number, at: number): RunnerEvent[] {
    this.index = index;
    this.stepStart = at;
    this.lastElapsed = -1;
    const step = this.current();
    if (!step) {
      this.ended = true;
      return [{ type: 'finished' }];
    }
    return [{ type: 'step', index, step }, ...this.dueCues(step)];
  }

  private dueCues(step: Step): RunnerEvent[] {
    const t = this.elapsedInStep();
    const prev = this.lastElapsed;
    this.lastElapsed = t;
    if (step.kind !== 'timed') return [];

    const due = (at: number) => at > prev && at <= t && t - at < STALE_SEC;
    const events: RunnerEvent[] = [];
    for (const cue of step.cues) {
      if (due(cue.at)) events.push({ type: 'say', text: cue.say });
    }
    for (const remaining of [3, 2, 1]) {
      const at = step.durationSec - remaining;
      if (at > 0 && due(at)) events.push({ type: 'beep', remaining });
    }
    return events;
  }
}
```

```ts
import type { TimedStep } from '../program/types';

export const OUT_OF_ZONE_SEC = 20;
export const REPEAT_SEC = 60;
/** Heart rate lags effort, so a hard interval gets this long before "Push a bit". */
export const HARD_GRACE_SEC = 90;

export class ZoneCoach {
  private stepId: string | null = null;
  private belowSince: number | null = null;
  private aboveSince: number | null = null;
  private lastSaidAt = -Infinity;

  /** `t` = seconds into the step, `bpm` 0 = no signal. Returns a phrase to speak, or null. */
  update(step: TimedStep, t: number, bpm: number): string | null {
    if (step.id !== this.stepId) {
      this.stepId = step.id;
      this.belowSince = null;
      this.aboveSince = null;
      this.lastSaidAt = -Infinity;
    }
    const target = step.target;
    if (!target || bpm <= 0) return null;

    if (bpm < target.low) {
      this.aboveSince = null;
      this.belowSince ??= t;
    } else if (bpm > target.high) {
      this.belowSince = null;
      this.aboveSince ??= t;
    } else {
      this.belowSince = null;
      this.aboveSince = null;
      return null;
    }

    if (t - this.lastSaidAt < REPEAT_SEC) return null;
    const hard = step.phase === 'hard';
    if (this.aboveSince !== null && t - this.aboveSince >= OUT_OF_ZONE_SEC) {
      this.lastSaidAt = t;
      return hard ? 'Ease off slightly' : 'Ease off';
    }
    if (
      this.belowSince !== null &&
      t - this.belowSince >= OUT_OF_ZONE_SEC &&
      (!hard || t >= HARD_GRACE_SEC)
    ) {
      this.lastSaidAt = t;
      return 'Push a bit';
    }
    return null;
  }
}
```

```ts
import type { HrReading } from './types';

/** Bluetooth Heart Rate Measurement (0x2A37): flag bit 0 selects an 8- or 16-bit value. */
export function parseHeartRate(view: DataView): number {
  const flags = view.getUint8(0);
  return flags & 0x01 ? view.getUint16(1, true) : view.getUint8(1);
}

export const STALE_MS = 3000;

/** The latest bpm if it arrived within `maxAgeMs`, otherwise 0 (no signal). */
export function freshBpm(reading: HrReading | null, now: number, maxAgeMs = STALE_MS): number {
  return reading && now - reading.at <= maxAgeMs ? reading.bpm : 0;
}
```

```ts
  return Math.round(125 + 55 * Math.max(0, Math.sin(sec / 70)) + 3 * Math.sin(sec / 7));
}

  /** bpm for a given second since connecting; 0 simulates a lost signal. */
  bpmAt?: (sec: number) => number;
  now?: () => number;
  connectDelayMs?: number;
}

export function createFakeSource({
  bpmAt = defaultFakeBpm,
  now = Date.now,
  connectDelayMs = 300,
}: FakeOptions = {}): HrSource {
  let status: HrStatus = 'idle';
  let latest: HrReading | null = null;
  let timer: ReturnType<typeof setInterval> | null = null;
  let startedAt = 0;
  const subs = new Set<() => void>();
  const emit = () => subs.forEach((cb) => cb());

  return {
    status: () => status,
    latest: () => latest,
    subscribe(cb) {
      subs.add(cb);
      return () => {
        subs.delete(cb);
      };
    },
    connect() {
      status = 'connecting';
      emit();
      return new Promise((resolve) => {
        setTimeout(() => {
          status = 'connected';
          startedAt = now();
          emit();
          timer ??= setInterval(() => {

            if (bpm > 0) latest = { bpm, at: now() };
            status = bpm > 0 ? 'connected' : 'reconnecting';
            emit();
          }, 1000);
          resolve();
        }, connectDelayMs);
      });
    },
    disconnect() {
      if (timer) clearInterval(timer);
      timer = null;
      status = 'idle';
      emit();
    },
  };
}
```

```ts
import { parseHeartRate } from './parse';
import type { HrReading, HrSource, HrStatus } from './types';

export interface StrapMemory {
  get(): string | undefined;
  set(id: string | undefined): void;
}

export const RETRY_MS = 5000;
export const CONNECT_TIMEOUT_MS = 10_000;

function withTimeout<T>(promise: Promise<T>, ms: number): Promise<T> {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(new Error('Timed out')), ms);
    promise.then(
      (value) => {
        clearTimeout(timer);
        resolve(value);
      },
      (err) => {
        clearTimeout(timer);
        reject(err);
      },
    );
  });
}

export function createBluetoothSource(
  memory: StrapMemory,
  bt: Bluetooth | undefined = globalThis.navigator?.bluetooth,
): HrSource {
  let status: HrStatus = bt ? 'idle' : 'unavailable';
  let latest: HrReading | null = null;
  let device: BluetoothDevice | null = null;
  let wanted = false;
  let retry: ReturnType<typeof setInterval> | null = null;
  const subs = new Set<() => void>();
  const emit = () => subs.forEach((cb) => cb());
  const setStatus = (next: HrStatus) => {
    status = next;
    emit();
  };

  const onValue = (event: Event) => {
    const value = (event.target as BluetoothRemoteGATTCharacteristic).value;
    if (!value) return;
    latest = { bpm: parseHeartRate(value), at: Date.now() };
    emit();
  };

  async function subscribeTo(d: BluetoothDevice): Promise<void> {
    if (!d.gatt) throw new Error('This device has no GATT server');
    const server = await withTimeout(d.gatt.connect(), CONNECT_TIMEOUT_MS);
    const service = await server.getPrimaryService('heart_rate');
    const ch = await service.getCharacteristic('heart_rate_measurement');
    ch.removeEventListener('characteristicvaluechanged', onValue);
    ch.addEventListener('characteristicvaluechanged', onValue);
    await ch.startNotifications();
  }

  function stopRetry() {
    if (retry) clearInterval(retry);
    retry = null;
  }

  function startRetry() {
    if (retry) return;
    retry = setInterval(() => {
      if (!device || !wanted) {
        stopRetry();
        return;
      }
      subscribeTo(device).then(
        () => {
          stopRetry();
          setStatus('connected');
        },
        () => {
          // Still out of range; the next interval tries again.
        },
      );
    }, RETRY_MS);
  }

  const onDisconnected = () => {
    if (!wanted) return;
    setStatus('reconnecting');
    startRetry();
  };

  async function remembered(): Promise<BluetoothDevice | null> {
    const id = memory.get();
    if (!id || !bt || typeof bt.getDevices !== 'function') return null;
    const devices = await bt.getDevices();
    return devices.find((d) => d.id === id) ?? null;
  }

  return {
    status: () => status,
    latest: () => latest,
    subscribe(cb) {
      subs.add(cb);
      return () => {

          (await bt.requestDevice({ filters: [{ services: ['heart_rate'] }] }));

          device?.removeEventListener('gattserverdisconnected', onDisconnected);
          d.addEventListener('gattserverdisconnected', onDisconnected);
          device = d;
        }
        memory.set(d.id);
        await subscribeTo(d);
        setStatus('connected');
      } catch (err) {
        wanted = false;
        setStatus('idle');
        throw err;
      }
    },
    disconnect() {
      wanted = false;
      stopRetry();
      device?.gatt?.disconnect();
      setStatus('idle');
```

```ts
import { openDB, type DBSchema } from 'idb';
import {
  DEFAULT_SETTINGS,
  type HrTraceRecord,
  type SessionRecord,
  type SetRecord,
  type Settings,
} from '../model';

interface EverydayDB extends DBSchema {
  settings: { key: string; value: Settings };
  sessions: { key: string; value: SessionRecord; indexes: { byStartedAt: number } };
  sets: { key: string; value: SetRecord; indexes: { bySession: string } };
  hrTraces: { key: string; value: HrTraceRecord };
}

export const DB_VERSION = 1;
const SETTINGS_KEY = 'settings';

export interface AllData {
  settings: Settings;
  sessions: SessionRecord[];
  sets: SetRecord[];
  traces: HrTraceRecord[];
}

export interface Store {
  getSettings(): Promise<Settings>;
  saveSettings(settings: Settings): Promise<void>;
  putSession(session: SessionRecord): Promise<void>;
  getSession(id: string): Promise<SessionRecord | undefined>;
  /** Oldest first. */
  listSessions(): Promise<SessionRecord[]>;
  addSet(set: SetRecord): Promise<void>;
  deleteSet(id: string): Promise<void>;
  setsFor(sessionId: string): Promise<SetRecord[]>;
  allSets(): Promise<SetRecord[]>;
  putTrace(trace: HrTraceRecord): Promise<void>;
  getTrace(sessionId: string): Promise<HrTraceRecord | undefined>;
  allTraces(): Promise<HrTraceRecord[]>;
  replaceAll(data: AllData): Promise<void>;
}

export async function openStore(name = 'everyday'): Promise<Store> {
  const db = await openDB<EverydayDB>(name, DB_VERSION, {
    upgrade(db) {
      db.createObjectStore('settings');
      db.createObjectStore('sessions', { keyPath: 'id' }).createIndex('byStartedAt', 'startedAt');
      db.createObjectStore('sets', { keyPath: 'id' }).createIndex('bySession', 'sessionId');
      db.createObjectStore('hrTraces', { keyPath: 'sessionId' });
    },
  });

  return {
    async getSettings() {
      const saved = await db.get('settings', SETTINGS_KEY);
      return { ...DEFAULT_SETTINGS, ...saved };
    },
    async saveSettings(settings) {
      await db.put('settings', settings, SETTINGS_KEY);
    },
    async putSession(session) {
      await db.put('sessions', session);
    },
    getSession: (id) => db.get('sessions', id),
    listSessions: () => db.getAllFromIndex('sessions', 'byStartedAt'),
    async addSet(set) {
      await db.put('sets', set);
    },
    async deleteSet(id) {
      await db.delete('sets', id);
    },
    setsFor: (sessionId) => db.getAllFromIndex('sets', 'bySession', sessionId),
    allSets: () => db.getAll('sets'),
    async putTrace(trace) {
      await db.put('hrTraces', trace);
    },
    getTrace: (sessionId) => db.get('hrTraces', sessionId),
    allTraces: () => db.getAll('hrTraces'),
    async replaceAll(data) {
      const tx = db.transaction(['settings', 'sessions', 'sets', 'hrTraces'], 'readwrite');
      await Promise.all([
        tx.objectStore('settings').clear(),
        tx.objectStore('sessions').clear(),
        tx.objectStore('sets').clear(),
        tx.objectStore('hrTraces').clear(),
      ]);
      await tx.objectStore('settings').put(data.settings, SETTINGS_KEY);
      for (const s of data.sessions) await tx.objectStore('sessions').put(s);
      for (const s of data.sets) await tx.objectStore('sets').put(s);
      for (const t of data.traces) await tx.objectStore('hrTraces').put(t);
      await tx.done;
    },
  };
}
```

```ts
import type { HrTraceRecord, SessionRecord, SetRecord, Settings } from '../model';
import { todayISO } from '../program/schedule';
import type { Store } from './store';

export const BACKUP_VERSION = 1;

export interface Backup {
  app: 'everyday';
  version: number;
  exportedAt: number;
  settings: Settings;
  sessions: SessionRecord[];
  sets: SetRecord[];
  traces: HrTraceRecord[];
}

export async function exportBackup(store: Store, now = Date.now()): Promise<Backup> {
  const [settings, sessions, sets, traces] = await Promise.all([
    store.getSettings(),
    store.listSessions(),
    store.allSets(),
    store.allTraces(),
  ]);
  return { app: 'everyday', version: BACKUP_VERSION, exportedAt: now, settings, sessions, sets, traces };
}

export function parseBackup(text: string): Backup {
  let data: Partial<Backup> | null;
  try {
    data = JSON.parse(text) as Partial<Backup> | null;
  } catch {
    throw new Error("That file isn't a backup. Pick an Everyday backup file.");
  }
  if (data?.app !== 'everyday') throw new Error("That file isn't an Everyday backup.");
  if (data.version !== BACKUP_VERSION) {
    throw new Error(`This backup is version ${data.version}. This app reads version ${BACKUP_VERSION}.`);
  }
  if (!data.settings || !Array.isArray(data.sessions) || !Array.isArray(data.sets) || !Array.isArray(data.traces)) {
    throw new Error('This backup is incomplete.');
  }
  return data as Backup;
}

export function describeBackup(backup: Backup): string {
  const n = backup.sessions.length;
  if (n === 0) return 'No sessions';
  const dates = backup.sessions.map((s) => s.plannedDate).sort();
  return `${n} session${n === 1 ? '' : 's'} from ${dates[0]} to ${dates[dates.length - 1]}`;
}

export async function importBackup(store: Store, backup: Backup): Promise<void> {
  await store.replaceAll({
    settings: backup.settings,
    sessions: backup.sessions,
    sets: backup.sets,
    traces: backup.traces,
  });
}

export function backupFileName(now = new Date()): string {
  return `everyday-backup-${todayISO(now)}.json`;
}

/** Opens the Android share sheet (e.g. to Google Drive); falls back to a download. */
export async function shareOrDownload(backup: Backup, now = new Date()): Promise<'shared' | 'downloaded'> {
  const name = backupFileName(now);
  const file = new File([JSON.stringify(backup)], name, { type: 'application/json' });
  if (navigator.canShare?.({ files: [file] })) {
    await navigator.share({ files: [file], title: 'Everyday backup' });
    return 'shared';
  }
  const url = URL.createObjectURL(file);
  const link = document.createElement('a');
  link.href = url;
  link.download = name;
  link.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
  return 'downloaded';
}
```

```ts
  return plannedDate === doneDate ? 'done' : 'moved';

  return s.status === 'done' || s.status === 'moved';

/** The most recent session that was interrupted less than 12 h ago. */
export function resumable(sessions: SessionRecord[], now: number): SessionRecord | undefined {
  return sessions
    .filter((s) => s.status === 'in_progress' && now - s.startedAt <= STALE_IN_PROGRESS_MS)
    .sort((a, b) => b.startedAt - a.startedAt)[0];
}

export function routineFor(s: SessionRecord): Step[] {
  switch (s.kind) {
    case 'morning':
      return morningRoutine();
    case 'kb': {
      const { circuit, roundRestSec } = s.params;
      if (!circuit || !roundRestSec) throw new Error(`Kettlebell session ${s.id} has no circuit`);
```

```ts
import type { SessionRecord } from '../model';
import { addDays, trainingFor, weekDates, weekStart, type TrainingDays } from '../program/schedule';
import type { TrainingKind } from '../program/types';
import { isComplete } from './session';

export type DayStatus = 'done' | 'moved' | 'partial' | 'missed' | 'today' | 'upcoming' | 'rest';

export interface WeekDay {
  date: string;
  training: TrainingKind | null;
  status: DayStatus;
  morningDone: boolean;
}

/** The finished (or, failing that, partial) session for a planned training day. */
export function trainingSessionFor(
  date: string,
  kind: TrainingKind,
  sessions: SessionRecord[],
): SessionRecord | undefined {
  const matches = sessions.filter((s) => s.kind === kind && s.plannedDate === date && s.status !== 'in_progress');
  return matches.find(isComplete) ?? matches[0];
}

/** The earliest planned date of any session; nothing before it counts as missed. */
export function firstDay(sessions: SessionRecord[]): string | null {
  return sessions.reduce<string | null>((min, s) => (min === null || s.plannedDate < min ? s.plannedDate : min), null);
}

function statusOf(
  date: string,
  today: string,
  since: string,
  training: TrainingKind | null,
  sessions: SessionRecord[],
): DayStatus {
  if (!training) return 'rest';
  const s = trainingSessionFor(date, training, sessions);
  if (s && s.status !== 'in_progress') return s.status;
  if (date < today) return date < since ? 'rest' : 'missed';
  return date === today ? 'today' : 'upcoming';
}

export function weekView(today: string, days: TrainingDays, sessions: SessionRecord[]): WeekDay[] {
  const since = firstDay(sessions) ?? today;
  return weekDates(today).map((date) => {
    const training = trainingFor(date, days);
    return {
      date,
      training,
      status: statusOf(date, today, since, training, sessions),
      morningDone: sessions.some((s) => s.kind === 'morning' && s.plannedDate === date && s.status === 'done'),
    };
  });
}

function finishedTrainingIn(week: string, sessions: SessionRecord[]): number {
  return sessions.filter((s) => s.kind !== 'morning' && isComplete(s) && weekStart(s.plannedDate) === week).length;
}

export function sessionsThisWeek(today: string, sessions: SessionRecord[]): number {
  return finishedTrainingIn(weekStart(today), sessions);
}

export function plannedPerWeek(days: TrainingDays): number {
  return Object.values(days).filter(Boolean).length;
}

export function makeUpCandidates(
  today: string,
  days: TrainingDays,
  sessions: SessionRecord[],
): { date: string; kind: TrainingKind }[] {
  return weekView(today, days, sessions).flatMap((d) =>
    d.status === 'missed' && d.training ? [{ date: d.date, kind: d.training }] : [],
  );
}

export function weeklySessionCounts(
  today: string,
  sessions: SessionRecord[],
  weeks = 12,
): { weekStart: string; count: number }[] {
  const current = weekStart(today);
  return Array.from({ length: weeks }, (_, i) => {
    const ws = addDays(current, -7 * (weeks - 1 - i));
    return { weekStart: ws, count: finishedTrainingIn(ws, sessions) };
  });
}
```

```ts
import type { SessionRecord } from '../model';
import { addDays, daysBetween } from '../program/schedule';

export function morningStreak(today: string, sessions: SessionRecord[]): { current: number; best: number } {
  const done = new Set(
    sessions.filter((s) => s.kind === 'morning' && s.status === 'done').map((s) => s.plannedDate),
  );

  // Today not done yet doesn't break the streak; it starts counting from yesterday.
  let current = 0;
  let day = done.has(today) ? today : addDays(today, -1);
  while (done.has(day)) {
    current++;
    day = addDays(day, -1);
  }

  let best = 0;
  let run = 0;
  let prev: string | null = null;
  for (const date of [...done].sort()) {
    run = prev && daysBetween(prev, date) === 1 ? run + 1 : 1;
    best = Math.max(best, run);
    prev = date;
  }
  return { current, best: Math.max(best, current) };
}
```

```ts
import type { RoundRest, SessionRecord, SetRecord } from '../model';
import { EXERCISES } from '../program/exercises';
import { KB_ROUNDS, type CircuitEntry } from '../program/routines';
import { addDays, weekStart, weekdayOf, type TrainingDays } from '../program/schedule';
import type { ExerciseId } from '../program/types';
import { isComplete } from './session';
import { plannedPerWeek } from './week';

export type SlotId = 'swing' | 'press' | 'windmill' | 'renegade';

export const SLOTS: SlotId[] = ['swing', 'press', 'windmill', 'renegade'];

export const SLOT_EXERCISES: Record<SlotId, ExerciseId[]> = {
  swing: ['single-arm-swing'],
  press: ['clean-and-press'],
  windmill: ['low-windmill', 'overhead-windmill'],
  renegade: ['renegade-row-push-up'],
};

export const REP_LADDER: Record<SlotId, number[]> = {
  swing: [10, 12, 15],
  press: [10, 12, 15],
  windmill: [10, 12, 15],
  renegade: [5, 6, 8],
};

/** Used in the Monday summary line. */
export const SLOT_LABEL: Record<SlotId, string> = {
  swing: 'Swings',
  press: 'Clean and press',
  windmill: 'Windmill',
  renegade: 'Renegade rows',
};

export const DEFAULT_CIRCUIT: CircuitEntry[] = [
  { exerciseId: 'single-arm-swing', repsPerSide: 10, weightKg: 12 },
  { exerciseId: 'clean-and-press', repsPerSide: 10, weightKg: 8 },
  { exerciseId: 'low-windmill', repsPerSide: 10, weightKg: 8 },
  { exerciseId: 'renegade-row-push-up', repsPerSide: 5, weightKg: 8 },
];

export const REST_STEPS: RoundRest[] = [90, 75, 60];

export function slotOf(id: ExerciseId): SlotId | null {
  return SLOTS.find((slot) => SLOT_EXERCISES[slot].includes(id)) ?? null;
}

const sorted = (bells: number[]) => [...bells].sort((a, b) => a - b);

export function nextStep(slot: SlotId, current: CircuitEntry, bellsKg: number[]): CircuitEntry | null {
  const bells = sorted(bellsKg);
  const reps = REP_LADDER[slot];
  if (current.exerciseId === 'low-windmill') {
    return { exerciseId: 'overhead-windmill', weightKg: bells[0], repsPerSide: reps[0] };
  }
  const heavier = bells.find((b) => b > current.weightKg);
  if (heavier !== undefined) return { ...current, weightKg: heavier, repsPerSide: reps[0] };
  const moreReps = reps.find((r) => r > current.repsPerSide);
  return moreReps !== undefined ? { ...current, repsPerSide: moreReps } : null;
}

export interface KbHistoryItem {
  session: SessionRecord;
  sets: SetRecord[];
}

export function kbHistory(sessions: SessionRecord[], sets: SetRecord[]): KbHistoryItem[] {
  return sessions
    .filter((s) => s.kind === 'kb' && (isComplete(s) || s.status === 'partial'))
    .sort((a, b) => a.startedAt - b.startedAt)
    .map((session) => ({ session, sets: sets.filter((x) => x.sessionId === session.id) }));
}

function slotSets(slot: SlotId, item: KbHistoryItem): SetRecord[] {
  return item.sets.filter((s) => s.block === 'circuit' && SLOT_EXERCISES[slot].includes(s.exerciseId));
}

export function stepUsed(slot: SlotId, item: KbHistoryItem): CircuitEntry | null {
  const first = slotSets(slot, item)[0];
  if (!first || first.weightKg === null) return null;
  return { exerciseId: first.exerciseId, weightKg: first.weightKg, repsPerSide: first.plannedRepsPerSide };
}

const sameStep = (a: CircuitEntry, b: CircuitEntry) =>
  a.exerciseId === b.exerciseId && a.weightKg === b.weightKg && a.repsPerSide === b.repsPerSide;

/** All rounds done at the planned reps with the planned bell, and the session rated Easy or Right. */
export function isClean(slot: SlotId, item: KbHistoryItem): boolean {
  const rating = item.session.rating;
  if (rating !== 'easy' && rating !== 'right') return false;
  const sets = slotSets(slot, item);
  const step = stepUsed(slot, item);
  if (!step || sets.length < KB_ROUNDS) return false;
  return sets.every(
    (s) => s.repsPerSide >= s.plannedRepsPerSide && s.weightKg === step.weightKg && s.exerciseId === step.exerciseId,
  );
}

/** Consecutive clean sessions at the newest step, counting back from the newest session. */
export function cleanCount(slot: SlotId, history: KbHistoryItem[]): { step: CircuitEntry | null; count: number } {
  let step: CircuitEntry | null = null;
  let count = 0;
  for (let i = history.length - 1; i >= 0; i--) {
    const used = stepUsed(slot, history[i]);
    if (!step) step = used;
    if (!used || !step || !sameStep(used, step) || !isClean(slot, history[i])) break;
    count++;
  }
  return { step, count };
}

function ownedOrLighter(weightKg: number, bellsKg: number[]): number {
  const bells = sorted(bellsKg);
  return [...bells].reverse().find((b) => b <= weightKg) ?? bells[0];
}

export function currentCircuit(history: KbHistoryItem[], bellsKg: number[]): CircuitEntry[] {
  return SLOTS.map((slot, i) => {
    for (let j = history.length - 1; j >= 0; j--) {
      const used = stepUsed(slot, history[j]);
      if (used) return used;
    }
    const d = DEFAULT_CIRCUIT[i];
    return { ...d, weightKg: ownedOrLighter(d.weightKg, bellsKg) };
  });
}

// ---------- Suggestions ----------

export type Suggestion =
  | { kind: 'step'; slot: SlotId; from: CircuitEntry; to: CircuitEntry }
  | { kind: 'ladder-end'; slot: SlotId }
  | { kind: 'rest'; fromSec: RoundRest; toSec: RoundRest };

export function suggestions(history: KbHistoryItem[], bellsKg: number[], roundRestSec: RoundRest): Suggestion[] {
  const out: Suggestion[] = [];
  for (const slot of SLOTS) {
    const { step, count } = cleanCount(slot, history);
    if (!step || count < 2) continue;
    const to = nextStep(slot, step, bellsKg);
    out.push(to ? { kind: 'step', slot, from: step, to } : { kind: 'ladder-end', slot });
  }

  const top = Math.max(...bellsKg);
  const circuit = currentCircuit(history, bellsKg);
  const allAtTop = circuit.every((c) => c.weightKg >= top && c.exerciseId !== 'low-windmill');
  const lastTwo = history.slice(-2);
  const lastTwoClean =
    lastTwo.length === 2 &&
    lastTwo.every((item) => item.session.params.roundRestSec === roundRestSec && SLOTS.every((s) => isClean(s, item)));
  const i = REST_STEPS.indexOf(roundRestSec);
  if (allAtTop && lastTwoClean && i >= 0 && i < REST_STEPS.length - 1) {
    out.push({ kind: 'rest', fromSec: roundRestSec, toSec: REST_STEPS[i + 1] });
  }
  return out;
}

export function applyStep(circuit: CircuitEntry[], s: Extract<Suggestion, { kind: 'step' }>): CircuitEntry[] {
  return circuit.map((c) => (slotOf(c.exerciseId) === s.slot ? { ...s.to } : c));
}

export function describeSuggestion(s: Suggestion): string {
  if (s.kind === 'rest') return `Rest between rounds: cut to ${s.toSec} s`;
  const name = EXERCISES[SLOT_EXERCISES[s.slot][0]].name;
  if (s.kind === 'ladder-end') return `${name}: ready for a heavier bell`;
  const toName = EXERCISES[s.to.exerciseId].name;
  const what = s.to.exerciseId !== s.from.exerciseId ? `switch to ${toName}` : 'move up';
  return `${EXERCISES[s.from.exerciseId].name}: ${what} to ${s.to.weightKg} kg × ${s.to.repsPerSide} per side`;
}

export function slotHistory(
  slot: SlotId,
  history: KbHistoryItem[],
): { date: string; exerciseId: ExerciseId; weightKg: number; repsPerSide: number }[] {
  return history.flatMap((item) => {
    const used = stepUsed(slot, item);
    return used ? [{ date: item.session.plannedDate, ...used }] : [];
  });
}

export function lastWeekLine(
  today: string,
  days: TrainingDays,
  sessions: SessionRecord[],
  sets: SetRecord[],
  bellsKg: number[],
): string | null {
  if (weekdayOf(today) !== 0) return null;
  const lastMonday = addDays(today, -7);
  const done = sessions.filter(
    (s) => s.kind !== 'morning' && isComplete(s) && weekStart(s.plannedDate) === lastMonday,
  ).length;
  let line = `Last week: ${done} of ${plannedPerWeek(days)}.`;

  const history = kbHistory(sessions, sets);
  const before = history.filter((h) => h.session.plannedDate < lastMonday);
  const through = history.filter((h) => h.session.plannedDate < today);
  if (before.length > 0) {
    const a = currentCircuit(before, bellsKg);
    const b = currentCircuit(through, bellsKg);
    SLOTS.forEach((slot, i) => {
      if (b[i].exerciseId !== a[i].exerciseId) {
        line += ` ${EXERCISES[b[i].exerciseId].name} replaces ${EXERCISES[a[i].exerciseId].name.toLowerCase()}.`;
      } else if (b[i].weightKg > a[i].weightKg) {
        line += ` ${SLOT_LABEL[slot]} moved up to ${b[i].weightKg} kg.`;
      }
    });
  }
  return line;
}
```

```ts
import type { SessionRecord, SessionSummary } from '../model';
import { Z2_MAX_MAIN_MIN, Z2_START_MAIN_MIN, Z2_STEP_MIN } from '../program/routines';
import { addDays, weekStart } from '../program/schedule';
import type { Range, TimedStep } from '../program/types';
import { isComplete } from './session';

export interface StepWindow {
  step: TimedStep;
  /** First second of the step in the trace. */
  start: number;
  /** One past the last second. */
  end: number;
}

export function stepWindows(steps: TimedStep[]): StepWindow[] {
  let t = 0;
  return steps.map((step) => {
    const w = { step, start: t, end: t + step.durationSec };
    t = w.end;
    return w;
  });
}

const inRange = (bpm: number, r: Range) => bpm > 0 && bpm >= r.low && bpm <= r.high;

function secondsInRange(bpm: number[], w: StepWindow, r: Range): number {
  let n = 0;
  for (let i = w.start; i < Math.min(w.end, bpm.length); i++) if (inRange(bpm[i], r)) n++;
  return n;
}

export function timeInZone(bpm: number[], steps: TimedStep[]): number {
  return stepWindows(steps).reduce((sum, w) => sum + (w.step.target ? secondsInRange(bpm, w, w.step.target) : 0), 0);
}

export function zone2Share(bpm: number[], steps: TimedStep[]): number {
  const w = stepWindows(steps).find((x) => x.step.phase === 'main');
  if (!w?.step.target) return 0;
  return secondsInRange(bpm, w, w.step.target) / (w.end - w.start);
}

export function avgBpm(bpm: number[]): number | undefined {
  const valid = bpm.filter((b) => b > 0);
  return valid.length ? Math.round(valid.reduce((a, b) => a + b, 0) / valid.length) : undefined;
}

export function intervalPeaks(bpm: number[], steps: TimedStep[]): number[] {
  return stepWindows(steps)
    .filter((w) => w.step.phase === 'hard')
    .map((w) => Math.max(0, ...bpm.slice(w.start, w.end)));
}

export const RECOVERY_SEC = 60;

/** Mean bpm drop from the last second of each hard interval to `recoverySec` later. */
export function hrRecovery(bpm: number[], steps: TimedStep[], recoverySec = RECOVERY_SEC): number | null {
  const drops: number[] = [];
  for (const w of stepWindows(steps)) {
    if (w.step.phase !== 'hard') continue;
    const end = bpm[w.end - 1];
    const later = bpm[w.end - 1 + recoverySec];
    if (end > 0 && later > 0) drops.push(end - later);
  }
  return drops.length ? Math.round(drops.reduce((a, b) => a + b, 0) / drops.length) : null;
}

/** The highest bpm that was held (every second at or above it) for `run` seconds in a row. */
export function sustainedPeak(bpm: number[], run = 5): number {
  let best = 0;
  for (let i = 0; i + run <= bpm.length; i++) {
    const window = bpm.slice(i, i + run);
    if (window.every((b) => b > 0)) best = Math.max(best, Math.min(...window));
  }
  return best;
}

export function spinSummary(bpm: number[], steps: TimedStep[]): SessionSummary {
  const hasMain = steps.some((s) => s.phase === 'main');
  const hasHard = steps.some((s) => s.phase === 'hard');
  return {
    durationSec: bpm.length,
    avgBpm: avgBpm(bpm),
    timeInZoneSec: timeInZone(bpm, steps),
    ...(hasMain ? { zone2Share: zone2Share(bpm, steps) } : {}),
    ...(hasHard ? { intervalPeaks: intervalPeaks(bpm, steps), hrRecovery: hrRecovery(bpm, steps) } : {}),
    sustainedPeak: sustainedPeak(bpm),
  };
}

// ---------- Progression and trends ----------

export const Z2_MIN_SHARE = 0.8;

const finished = (sessions: SessionRecord[], kind: 'z2' | 'z5') =>
  sessions.filter((s) => s.kind === kind && isComplete(s)).sort((a, b) => a.startedAt - b.startedAt);

export function nextZone2MainMin(sessions: SessionRecord[]): number {
  let current = Z2_START_MAIN_MIN;
  let count = 0;
  for (const s of finished(sessions, 'z2')) {
    if (s.params.mainMin !== current || (s.summary?.zone2Share ?? 0) < Z2_MIN_SHARE) continue;
    count++;
    if (count === 2) {
      current = Math.min(Z2_MAX_MAIN_MIN, current + Z2_STEP_MIN);
      count = 0;
    }
  }
  return current;
}

export function weeklyZone2Minutes(
  today: string,
  sessions: SessionRecord[],
  weeks = 12,
): { weekStart: string; minutes: number }[] {
  const rides = finished(sessions, 'z2');
  const current = weekStart(today);
  return Array.from({ length: weeks }, (_, i) => {
    const ws = addDays(current, -7 * (weeks - 1 - i));
    const sec = rides
      .filter((s) => weekStart(s.plannedDate) === ws)
      .reduce((sum, s) => sum + (s.summary?.timeInZoneSec ?? 0), 0);
    return { weekStart: ws, minutes: Math.round(sec / 60) };
  });
}

export function z2MainTrend(sessions: SessionRecord[]): { date: string; mainMin: number }[] {
  return finished(sessions, 'z2').map((s) => ({ date: s.plannedDate, mainMin: s.params.mainMin ?? Z2_START_MAIN_MIN }));
}

export function z5Trend(
  sessions: SessionRecord[],
): { date: string; avgPeak: number | null; hrRecovery: number | null }[] {
  return finished(sessions, 'z5').map((s) => {
    const peaks = (s.summary?.intervalPeaks ?? []).filter((p) => p > 0);
    return {
      date: s.plannedDate,
      avgPeak: peaks.length ? Math.round(peaks.reduce((a, b) => a + b, 0) / peaks.length) : null,
      hrRecovery: s.summary?.hrRecovery ?? null,
    };
  });
}
```

```ts
import type { RunnerEvent } from '../engine/runner';
import { announce } from '../program/routines';

export interface CueOutputs {
  canSpeak(): boolean;
  speak(text: string): void;
  beep(kind: 'tick' | 'go' | 'end'): void;
  vibrate(pattern: number | number[]): void;
}

export interface CuePrefs {
  voice: boolean;
  beeps: boolean;
  vibration: boolean;
}

export interface CuePlayer {
  say(text: string): void;
  handle(events: RunnerEvent[]): void;
}

export function createCuePlayer(prefs: CuePrefs, out: CueOutputs): CuePlayer {
  const voiceOn = () => prefs.voice && out.canSpeak();
  const say = (text: string) => {
    if (voiceOn()) out.speak(text);
    else if (prefs.beeps) out.beep('go');
  };

  return {
    say,
    handle(events) {
      for (const e of events) {
        switch (e.type) {
          case 'say':
            say(e.text);
            break;
          case 'beep':
            if (prefs.beeps) out.beep('tick');
            break;
          case 'step':
            if (prefs.vibration) out.vibrate(150);
            if (e.step.kind === 'tap') say(announce(e.step));
            else if (prefs.beeps) out.beep('go');
            break;
          case 'finished':
            if (prefs.vibration) out.vibrate([200, 100, 200]);
            if (prefs.beeps) out.beep('end');
            if (voiceOn()) out.speak('Workout complete');
            break;
        }
      }
    },
  };
}
```

```ts
/** Keeps the screen on until the returned function is called. Re-acquires after the app is hidden and shown. */
export function keepAwake(): () => void {
  let lock: WakeLockSentinel | null = null;
  let active = true;

  const request = async () => {
    if (!active || document.visibilityState !== 'visible' || !('wakeLock' in navigator)) return;
    try {
      lock = await navigator.wakeLock.request('screen');
    } catch {
      // Not allowed right now (e.g. battery saver); the workout still runs.
    }
  };
  const onVisibility = () => {
    if (document.visibilityState === 'visible') void request();
  };

  document.addEventListener('visibilitychange', onVisibility);
  void request();

  return () => {
    active = false;
    document.removeEventListener('visibilitychange', onVisibility);
    void lock?.release();
    lock = null;
  };
}
```

```ts
import type { Drawing } from './poses';

const easeInOut = (x: number) => (x < 0.5 ? 2 * x * x : 1 - (-2 * x + 2) ** 2 / 2);

/** Joint coordinates `tSec` seconds into the drawing's loop. */
export function poseAt(d: Drawing, tSec: number): number[] {
  const n = d.frames.length;
  if (n === 1) return [...d.frames[0]];
  const stops = d.stops ?? d.frames.map((_, i) => i / (n - 1));
  const p = (((tSec % d.durationSec) + d.durationSec) % d.durationSec) / d.durationSec;

  let i = 0;
  while (i < n - 2 && p > stops[i + 1]) i++;
  const span = stops[i + 1] - stops[i];
  const local = span > 0 ? Math.min(1, (p - stops[i]) / span) : 0;
  const e = easeInOut(local);

  const a = d.frames[i];
  const b = d.frames[i + 1];
  return a.map((v, k) => v + (b[k] - v) * e);
}
```

```tsx
import { useEffect, useState } from 'preact/hooks';
import { EXERCISES } from '../program/exercises';
import type { ExerciseId } from '../program/types';
import { poseAt } from './interpolate';
import { DRAWINGS } from './poses';

type Pt = readonly [number, number];

const BODY = {
  fill: 'none',
  stroke: 'currentColor',
  strokeWidth: 4,
  strokeLinecap: 'round',
  strokeLinejoin: 'round',
} as const;

export function Figure({ exerciseId, size = 200 }: { exerciseId: ExerciseId; size?: number }) {
  const drawing = DRAWINGS[exerciseId];
  const [t, setT] = useState(0);

  useEffect(() => {
    if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
      setT(drawing.durationSec * (drawing.stops?.[1] ?? 0.5));
      return;
    }
    let raf = 0;
    const start = performance.now();
    const loop = (now: number) => {
      setT((now - start) / 1000);
      raf = requestAnimationFrame(loop);
    };
    raf = requestAnimationFrame(loop);
    return () => cancelAnimationFrame(raf);
  }, [exerciseId]);

  const p = poseAt(drawing, t);
  const joints: Pt[] = Array.from({ length: 11 }, (_, j) => [p[j * 2], p[j * 2 + 1]] as const);
  const [head, neck, hip, lElbow, lHand, rElbow, rHand, lKnee, lFoot, rKnee, rFoot] = joints;
  const line = (...pts: Pt[]) => pts.map(([x, y]) => `${x.toFixed(1)},${y.toFixed(1)}`).join(' ');
  const bells: Pt[] =
    drawing.bell === 'l' ? [lHand]
    : drawing.bell === 'r' ? [rHand]
    : drawing.bell === 'both' ? [[(lHand[0] + rHand[0]) / 2, (lHand[1] + rHand[1]) / 2]]
    : [];

  return (
    <svg viewBox="0 0 100 100" width={size} height={size} class="figure" role="img" aria-label={EXERCISES[exerciseId].name}>
      <line x1="4" y1="93" x2="96" y2="93" style={{ stroke: 'currentColor', strokeWidth: 1, opacity: 0.3 }} />
      <g style={BODY}>
        <polyline points={line(neck, hip)} />
        <polyline points={line(neck, lElbow, lHand)} />
        <polyline points={line(neck, rElbow, rHand)} />
        <polyline points={line(hip, lKnee, lFoot)} />
        <polyline points={line(hip, rKnee, rFoot)} />
        <circle cx={head[0]} cy={head[1]} r={6} />
      </g>
      {bells.map(([x, y], i) => (
        <circle key={i} cx={x} cy={y + 4} r={4.5} style={{ fill: 'var(--accent)' }} />
      ))}
    </svg>
  );
}
```

```ts
import type { SessionRecord } from '../model';
import { nextZone2MainMin } from '../progress/cardio';
import type { SessionKind } from '../program/types';

const pad = (n: number) => String(n).padStart(2, '0');

export function mmss(sec: number): string {
  const s = Math.max(0, Math.floor(sec));
  const h = Math.floor(s / 3600);
  const m = Math.floor((s % 3600) / 60);
  return h ? `${h}:${pad(m)}:${pad(s % 60)}` : `${m}:${pad(s % 60)}`;
}

export const KIND_LABEL: Record<SessionKind, string> = {
  morning: 'Morning routine',
  kb: 'Kettlebell',
  z2: 'Zone 2 ride',
  z5: 'Zone 5 ride',
};

export function estimatedMinutes(kind: SessionKind, sessions: SessionRecord[]): number {
  switch (kind) {
    case 'morning':
      return 5;
    case 'kb':
      return 35;
    case 'z2':
      return 10 + nextZone2MainMin(sessions);
    case 'z5':
      return 40;
  }
}

function localDate(date: string): Date {
  const [y, m, d] = date.split('-').map(Number);
  return new Date(y, m - 1, d);
}

export function dayName(date: string): string {
  return localDate(date).toLocaleDateString('en-GB', { weekday: 'long' });
}

export function shortDate(date: string): string {
  return localDate(date).toLocaleDateString('en-GB', { day: 'numeric', month: 'short' });
}

export const WEEKDAY_LETTERS = ['M', 'T', 'W', 'T', 'F', 'S', 'S'];
```

```tsx
import { createContext } from 'preact';
import { useContext } from 'preact/hooks';
import type { Store } from '../db/store';
import type { HrSource } from '../hr/types';
import type { SessionRecord, SetRecord, Settings } from '../model';
import type { TrainingKind } from '../program/types';

/** The training to run straight after the morning routine. */
export type Next = { kind: TrainingKind; plannedDate: string } | null;

export type Route =
  | { name: 'today' }
  | { name: 'progress' }
  | { name: 'calendar' }
  | { name: 'settings' }
  | { name: 'day'; date: string }
  | { name: 'morning'; sessionId: string; next: Next }
  | { name: 'kb-start'; plannedDate: string }
  | { name: 'kb'; sessionId: string }
  | { name: 'spin-start'; kind: 'z2' | 'z5'; plannedDate: string }
  | { name: 'spin'; sessionId: string }
  | { name: 'finish'; sessionId: string };

export interface AppData {
  store: Store;
  settings: Settings;
  /** Oldest first. */
  sessions: SessionRecord[];
  sets: SetRecord[];
  today: string;
  hr: HrSource;
  route: Route;
  go(route: Route): void;
  reload(): Promise<void>;
  saveSettings(settings: Settings): Promise<void>;
}

export const DataContext = createContext<AppData | null>(null);

export function useData(): AppData {
  const data = useContext(DataContext);
  if (!data) throw new Error('useData must be used inside <App>');
  return data;
}

export function useSession(id: string): SessionRecord | undefined {
  return useData().sessions.find((s) => s.id === id);
}
```

```ts
import type { SessionRecord } from '../model';
import type { CircuitEntry } from '../program/routines';
import type { TrainingKind } from '../program/types';
import { nextZone2MainMin } from '../progress/cardio';
import { completedStatus, newSession } from '../progress/session';
import type { AppData, Next } from './data';

export async function beginMorning(d: AppData, next: Next): Promise<void> {
  const s = newSession('morning', d.today, Date.now());
  await d.store.putSession(s);
  await d.reload();
  d.go({ name: 'morning', sessionId: s.id, next });
}

/** Opens the start screen; the session itself is only created when the user taps Start there. */
export async function beginTraining(d: AppData, kind: TrainingKind, plannedDate: string): Promise<void> {
  d.go(kind === 'kb' ? { name: 'kb-start', plannedDate } : { name: 'spin-start', kind, plannedDate });
}

export async function beginSpin(d: AppData, kind: 'z2' | 'z5', plannedDate: string): Promise<void> {
  const params =
    kind === 'z2'
      ? { maxHr: d.settings.maxHr, mainMin: nextZone2MainMin(d.sessions) }
      : { maxHr: d.settings.maxHr };
  const s = newSession(kind, plannedDate, Date.now(), params);
  await d.store.putSession(s);
  await d.reload();
  d.go({ name: 'spin', sessionId: s.id });
}

export async function beginKb(d: AppData, plannedDate: string, circuit: CircuitEntry[]): Promise<void> {
  const s = newSession('kb', plannedDate, Date.now(), { circuit, roundRestSec: d.settings.roundRestSec });
  await d.store.putSession(s);
  await d.reload();
  d.go({ name: 'kb', sessionId: s.id });
}

/** Remembers where to resume. Doesn't reload, so it's cheap to call on every step. */
export async function saveProgress(d: AppData, s: SessionRecord, stepIndex: number): Promise<void> {
  await d.store.putSession({ ...s, stepIndex });
}

export async function completeSession(
  d: AppData,
  s: SessionRecord,
  patch: Partial<SessionRecord> = {},
): Promise<SessionRecord> {
  const latest = (await d.store.getSession(s.id)) ?? s;
  const done: SessionRecord = {
    ...latest,
    ...patch,
    status: s.kind === 'morning' ? 'done' : completedStatus(s.plannedDate, d.today),
    doneDate: d.today,
    endedAt: Date.now(),
  };
  await d.store.putSession(done);
  await d.reload();
  return done;
}

export async function endPartial(d: AppData, s: SessionRecord, patch: Partial<SessionRecord> = {}): Promise<void> {
  const latest = (await d.store.getSession(s.id)) ?? s;
  await d.store.putSession({ ...latest, ...patch, status: 'partial', endedAt: Date.now() });
  await d.reload();
}
```

```tsx
export function Today() {

  const [backupError, setBackupError] = useState<string | null>(null);

      <Header
        title={dayName(today)}
        right={
          <button class="icon-btn" aria-label="Settings" onClick={() => d.go({ name: 'settings' })}>
            ⚙
```

```ts
import { useEffect, useRef, useState } from 'preact/hooks';
import { browserOutputs, stopSpeech } from '../cues/browser';
import { createCuePlayer, type CuePlayer, type CuePrefs } from '../cues/player';
import { keepAwake } from '../cues/wakeLock';
import { Runner, type RunnerEvent } from '../engine/runner';
import type { Step } from '../program/types';
import { now } from './clock';

export interface RunnerHooks {
  onStep?(index: number): void;
  onFinish?(): void;
  /** Called on every tick (4 times a second), after the tick's events. */
  onTick?(runner: Runner): void;
}

/** Runs `steps` with cues and the screen kept awake; re-renders the caller 4 times a second. */
export function useRunner(steps: Step[], startIndex: number, prefs: CuePrefs, hooks: RunnerHooks = {}) {
  const runnerRef = useRef<Runner | null>(null);
  runnerRef.current ??= new Runner(steps, now, startIndex);
  const runner = runnerRef.current;

  const cuesRef = useRef<CuePlayer | null>(null);
  cuesRef.current ??= createCuePlayer(prefs, browserOutputs);
  const cues = cuesRef.current;

  const hooksRef = useRef(hooks);
  hooksRef.current = hooks;
  const [, setFrame] = useState(0);
  const rerender = () => setFrame((f) => f + 1);

  const handle = (events: RunnerEvent[]) => {
    cues.handle(events);
    for (const e of events) {
      if (e.type === 'step') hooksRef.current.onStep?.(e.index);
      if (e.type === 'finished') hooksRef.current.onFinish?.();
    }
    rerender();
  };

  useEffect(() => {
    handle(runner.start());
    const release = keepAwake();
    const id = setInterval(() => {
      handle(runner.tick());
      hooksRef.current.onTick?.(runner);
    }, 250);
    return () => {
      clearInterval(id);
      release();
      stopSpeech();
    };
  }, []);

  return {
    runner,
    say: (text: string) => cues.say(text),
    done: () => handle(runner.done()),
    back: () => handle(runner.back()),
    pause: () => {
      runner.pause();
      rerender();
    },
    resume: () => {
      runner.resume();
      rerender();
    },
  };
}
```

```tsx
function repsText(step: TapStep): string {
  if (step.block === 'warmup') {
    return step.items.map((i) => `${i.reps} ${EXERCISES[i.exerciseId].name.toLowerCase()}`).join(' · ');
  }
  const item = step.items[0];
  const reps = EXERCISES[item.exerciseId].perSide ? `${item.reps} per side` : `${item.reps}`;

function KbRun({ session }: { session: SessionRecord }) {
  const d = useData();
  const steps = useMemo(() => routineFor(session), [session.id]);
  const [picker, setPicker] = useState(false);
  const [undo, setUndo] = useState<string[] | null>(null);
  const [confirmEnd, setConfirmEnd] = useState(false);
  const holdTimer = useRef<ReturnType<typeof setTimeout> | null>(null);
  const held = useRef(false);

    onStep: (i) => void saveProgress(d, session, i),
    onFinish: async () => {
      await saveProgress(d, session, steps.length);

    if (!undo) return;

    const records: SetRecord[] = step.items.map((item) => ({
      id: crypto.randomUUID(),
      sessionId: session.id,
      exerciseId: item.exerciseId,
      block: step.block,
      round: step.round,
      repsPerSide: reps ?? item.reps,
      plannedRepsPerSide: item.reps,
      weightKg: step.weightKg,
      at,
    }));
    void Promise.all(records.map((r) => d.store.addSet(r)));
    setUndo(records.map((r) => r.id));
    done();
  };

  const undoLast = async () => {
    if (!undo) return;
    const ids = undo;
    setUndo(null);
    await Promise.all(ids.map((id) => d.store.deleteSet(id)));
    back();
  };

  const cancelHold = () => {
    if (holdTimer.current) clearTimeout(holdTimer.current);
    holdTimer.current = null;
  };
  const onDown = () => {
    held.current = false;
    if (step.kind !== 'tap' || step.block !== 'circuit') return;
    holdTimer.current = setTimeout(() => {
      held.current = true;
      setPicker(true);
      navigator.vibrate?.(30);
    }, HOLD_MS);
  };
  const onUp = () => {
    cancelHold();
    if (!held.current) complete();
  };

  const endHere = async () => {
    await endPartial(d, session);
    d.go({ name: 'today' });
  };

  const nextTap = steps.slice(runner.stepIndex + 1).find((s): s is TapStep => s.kind === 'tap');
  const top =
    step.kind === 'tap'
      ? step.block === 'warmup'
        ? `Warm-up · round ${step.round} of 2`
        : `Circuit · round ${step.round} of 3`
      : step.title;

  return (
    <main class="player">
      <div class="player-top">
        <span>{top}</span>
        <button class="btn btn-quiet" onClick={() => setConfirmEnd(true)}>
          End
        </button>
      </div>

      {confirmEnd && (
        <div class="banner">
          <p>End this session here? It's saved as partly done.</p>
          <div class="btn-row">
            <button class="btn" onClick={() => setConfirmEnd(false)}>
              Keep going
            </button>
            <button class="btn" onClick={endHere}>
              End here
            </button>
          </div>
        </div>
      )}

      {step.kind === 'tap' ? (
        <>
          <div class="player-figure">
            {step.items.map((item) => (
              <Figure key={item.exerciseId} exerciseId={item.exerciseId} size={step.items.length > 1 ? 100 : 200} />
            ))}
          </div>
          <h1 class="player-title">{step.block === 'warmup' ? 'Warm-up' : step.title}</h1>
          <p class="player-detail">{repsText(step)}</p>
          {step.block === 'circuit' && <p class="small muted">{EXERCISES[step.items[0].exerciseId].cue}</p>}
          <p class="small muted">Since last set {mmss(runner.elapsedInStep())}</p>

          {picker ? (
            <section class="card">
              <h2>{EXERCISES[step.items[0].exerciseId].perSide ? 'Reps per side done' : 'Reps done'}</h2>
              <div class="reps-picker">
                {Array.from({ length: step.items[0].reps + 2 }, (_, i) => i + 1).map((n) => (
                  <button key={n} class="btn" onClick={() => complete(n)}>
                    {n}
                  </button>
                ))}
              </div>
              <button class="btn btn-quiet" onClick={() => setPicker(false)}>
                Cancel
              </button>
            </section>
          ) : (
            <button
              class="done-btn"
              onPointerDown={onDown}
              onPointerUp={onUp}
              onPointerLeave={cancelHold}
              onPointerCancel={cancelHold}
              onContextMenu={(e) => e.preventDefault()}
            >
              Done
            </button>
          )}
          {!picker && step.block === 'circuit' && <p class="small muted">Hold Done to change reps</p>}
        </>
      ) : (
        <>
          <h1 class="player-title">{step.title}</h1>
          {step.detail && <p class="player-detail">{step.detail}</p>}
          <div class="countdown">{mmss(Math.ceil(runner.remainingInStep()))}</div>
          <div class="bar">
            <span style={{ width: `${(1 - runner.remainingInStep() / step.durationSec) * 100}%` }} />
          </div>
          {nextTap && (
            <p class="player-next">
              Next: {nextTap.block === 'warmup' ? 'Warm-up' : nextTap.title} · {repsText(nextTap)}
            </p>
          )}
          <div class="player-controls">
            {runner.paused ? (
              <button class="btn" onClick={resume}>
                Resume
              </button>
            ) : (
              <button class="btn" onClick={pause}>
                Pause
              </button>
            )}
            <button class="btn" onClick={done}>
              Skip rest
            </button>
          </div>
        </>
      )}

      {undo && (
        <button class="btn btn-quiet" onClick={undoLast}>
          Undo last set
        </button>
      )}
    </main>
  );
}
```

```ts
import type { HrSource } from '../hr/types';

/** Re-renders on every strap status change and reading. */
export function useHr(hr: HrSource) {
  const [, setTick] = useState(0);
  useEffect(() => hr.subscribe(() => setTick((n) => n + 1)), [hr]);
  return { status: hr.status(), latest: hr.latest() };
}
```

```tsx
import { useEffect, useMemo, useRef, useState } from 'preact/hooks';
import { ZoneCoach } from '../../engine/zoneCoach';
import { freshBpm } from '../../hr/parse';
import { TraceRecorder } from '../../hr/trace';
import type { HrStatus } from '../../hr/types';
import type { SessionRecord } from '../../model';
import { totalSec } from '../../program/routines';
import type { TimedStep } from '../../program/types';
import { positionIn } from '../../program/zones';
import { spinSummary, stepWindows } from '../../progress/cardio';
import { routineFor } from '../../progress/session';
import { SPEED } from '../clock';
import { MissingSession } from '../components/MissingSession';
import { useData, useSession } from '../data';
import { endPartial, saveProgress } from '../flow';
import { KIND_LABEL, mmss } from '../format';
import { useHr } from '../useHr';
import { useRunner } from '../useRunner';

const STATUS_LABEL: Record<HrStatus, string> = {
  idle: 'Strap off',
  connecting: 'Connecting…',
  connected: 'Strap on',
  reconnecting: 'Reconnecting…',
  unavailable: 'No Bluetooth',
};

/** Save the trace this often (seconds of ride). */
const FLUSH_SEC = 10;

export function SpinPlayer({ sessionId }: { sessionId: string }) {
  const session = useSession(sessionId);
  return session ? <Ride session={session} /> : <MissingSession />;
}

function Ride({ session }: { session: SessionRecord }) {
  const d = useData();
  const steps = useMemo(() => routineFor(session) as TimedStep[], [session.id]);
  const windows = useMemo(() => stepWindows(steps), [steps]);
  const total = totalSec(steps);
  const startIndex = session.stepIndex;
  // Seconds of the ride before the step we (re)start at; the trace is aligned to step boundaries.
  const offset = windows[startIndex]?.start ?? total;

  const trace = useRef<TraceRecorder | null>(null);
  trace.current ??= new TraceRecorder();
  const coach = useRef<ZoneCoach | null>(null);
  coach.current ??= new ZoneCoach();
  const lastSample = useRef(offset - 1);
  const lastFlush = useRef(offset);
  const prevStatus = useRef<HrStatus>(d.hr.status());
  const [confirmEnd, setConfirmEnd] = useState(false);
  const { status, latest } = useHr(d.hr);

  useEffect(() => {
    if (offset === 0) return;
    void d.store.getTrace(session.id).then((t) => {
      if (t) trace.current = new TraceRecorder(t.bpm.slice(0, offset));
    });
  }, []);

  const flush = () =>
    d.store.putTrace({ sessionId: session.id, startedAt: session.startedAt, bpm: trace.current!.snapshot() });

  const { runner, say, pause, resume } = useRunner(steps, startIndex, d.settings, {
    onStep: (i) => void saveProgress(d, session, i),
    onTick: (r) => {
      if (r.paused || r.finished) return;
      const sec = offset + Math.floor(r.totalElapsed());
      if (sec <= lastSample.current) return;
      const bpm = freshBpm(d.hr.latest(), Date.now());
      // At ?speed=N several ride seconds pass per tick; fill them so test rides have a full trace.
      for (let s = lastSample.current + 1; s < sec; s++) trace.current!.record(s, SPEED > 1 ? bpm : 0);
      trace.current!.record(sec, bpm);
      lastSample.current = sec;
      const step = r.current();
      if (step?.kind === 'timed') {
        const phrase = coach.current!.update(step, r.elapsedInStep(), bpm);
        if (phrase) say(phrase);
      }
      if (sec - lastFlush.current >= FLUSH_SEC) {
        lastFlush.current = sec;
        void flush();
      }
    },
    onFinish: async () => {
      d.hr.disconnect();
      await flush();
      await saveProgress(d, session, steps.length);
      d.go({ name: 'finish', sessionId: session.id });
    },
  });

  useEffect(() => {
    const prev = prevStatus.current;
    prevStatus.current = status;
    if (prev === 'connected' && status === 'reconnecting') say('Heart rate lost');
    if (prev === 'reconnecting' && status === 'connected') say('Heart rate back');
  }, [status]);

  const step = runner.current();
  if (!step || step.kind !== 'timed') return null;

  const bpm = freshBpm(latest, Date.now());
  const zone = step.target && bpm > 0 ? `zone-${positionIn(bpm, step.target)}` : '';
  const hard = steps.filter((s) => s.phase === 'hard');
  const hardDone = steps.slice(0, runner.stepIndex).filter((s) => s.phase === 'hard').length;
  const elapsed = Math.min(total, offset + runner.totalElapsed());

  const endRide = async () => {
    d.hr.disconnect();
    await flush();
    await endPartial(d, session, { summary: spinSummary(trace.current!.snapshot(), steps) });
    d.go({ name: 'today' });
  };

  return (
    <main class={`player spin ${zone}`}>
      <div class="player-top">
        <span>{KIND_LABEL[session.kind]}</span>
        <span>{STATUS_LABEL[status]}</span>
        <button class="btn btn-quiet" onClick={() => setConfirmEnd(true)}>
          End
        </button>
      </div>

      {confirmEnd && (
        <div class="banner">
          <p>End the ride here? It's saved as partly done.</p>
          <div class="btn-row">
            <button class="btn" onClick={() => setConfirmEnd(false)}>
              Keep riding
            </button>
            <button class="btn" onClick={endRide}>
              End here
            </button>
          </div>
        </div>
      )}

      <h1 class="player-title">{step.title}</h1>
      <p class="player-detail">{step.detail}</p>
      <div class="bpm">{bpm > 0 ? bpm : '––'}</div>
      <p style={{ textAlign: 'center' }}>
        {bpm > 0 ? 'bpm' : status === 'connected' ? 'Waiting for heart rate' : 'No heart rate'}
      </p>
      <div class="countdown">{mmss(Math.ceil(runner.remainingInStep()))}</div>
      <p class="player-next" style={{ textAlign: 'center' }}>
        left in this phase
      </p>
      {hard.length > 0 && (
        <div class="intervals" aria-label={`${hardDone} of ${hard.length} intervals done`}>
          {hard.map((s, i) => (
            <span key={s.id} class={i < hardDone ? 'done' : ''} />
          ))}
        </div>
      )}
      <div class="bar">
        <span style={{ width: `${(elapsed / total) * 100}%` }} />
```

```tsx
export interface LinePoint {
  label: string;
  value: number;
}

const W = 320;
const PAD_X = 22;
const PAD_TOP = 16;
const PAD_BOTTOM = 18;

export function LineChart({ points, unit = '', height = 120 }: { points: LinePoint[]; unit?: string; height?: number }) {
  if (points.length === 0) return <p class="muted small">Your first session will show up here.</p>;

  const values = points.map((p) => p.value);
  const min = Math.min(...values);
  const span = Math.max(...values) - min || 1;
  const x = (i: number) => (points.length === 1 ? W / 2 : PAD_X + (i * (W - 2 * PAD_X)) / (points.length - 1));
  const y = (v: number) => height - PAD_BOTTOM - ((v - min) / span) * (height - PAD_TOP - PAD_BOTTOM);
  const path = points.map((p, i) => `${i ? 'L' : 'M'}${x(i).toFixed(1)},${y(p.value).toFixed(1)}`).join(' ');
  const last = points[points.length - 1];

  return (
    <svg
      class="chart"
      viewBox={`0 0 ${W} ${height}`}
      role="img"
      aria-label={points.map((p) => `${p.label} ${p.value}${unit}`).join(', ')}
    >
      <line class="grid" x1={0} x2={W} y1={height - PAD_BOTTOM} y2={height - PAD_BOTTOM} />
      <path d={path} style={{ fill: 'none', stroke: 'currentColor', strokeWidth: 2 }} />
      {points.map((p, i) => (
        <circle key={i} cx={x(i)} cy={y(p.value)} r={3} fill="currentColor" />
      ))}
      <text x={x(0)} y={height - 4}>
        {points[0].label}
      </text>
      {points.length > 1 && (
        <text x={x(points.length - 1)} y={height - 4}>
          {last.label}
        </text>
      )}
      <text x={x(points.length - 1)} y={y(last.value) - 6}>
        {last.value}
        {unit}
      </text>
    </svg>
  );
}
```

```ts
import { addDays, weekStart } from '../program/schedule';

/** 6 weeks × 7 days of dates covering `month` (1–12) of `year`, Monday first. */
export function monthGrid(year: number, month: number): string[] {
  const start = weekStart(`${year}-${String(month).padStart(2, '0')}-01`);
  return Array.from({ length: 42 }, (_, i) => addDays(start, i));
}

export function monthOf(date: string): { year: number; month: number } {
  const [year, month] = date.split('-').map(Number);
  return { year, month };
}

export function shiftMonth(year: number, month: number, delta: number): { year: number; month: number } {
  const index = year * 12 + (month - 1) + delta;
  return { year: Math.floor(index / 12), month: (index % 12) + 1 };
}

export function monthTitle(year: number, month: number): string {
  return new Date(year, month - 1, 1).toLocaleDateString('en-GB', { month: 'long', year: 'numeric' });
}
```

```tsx
import type { SessionRecord, SetRecord } from '../../model';
import { EXERCISES } from '../../program/exercises';
import type { ExerciseId } from '../../program/types';
import { Header } from '../components/Header';
import { useData } from '../data';
import { KIND_LABEL, dayName, mmss, shortDate } from '../format';

const RATING_LABEL = { easy: 'Easy', right: 'Right', hard: 'Hard' } as const;

function statusText(s: SessionRecord): string {
  if (s.status === 'moved' && s.doneDate) return `Done on ${dayName(s.doneDate)} ${shortDate(s.doneDate)}`;
  if (s.status === 'partial') return 'Partly done';
  return 'Done';
}

function KbDetail({ sets }: { sets: SetRecord[] }) {
  const circuit = sets.filter((s) => s.block === 'circuit').sort((a, b) => a.at - b.at);
  const order: ExerciseId[] = [];
  for (const s of circuit) if (!order.includes(s.exerciseId)) order.push(s.exerciseId);
  const warmupRounds = new Set(sets.filter((s) => s.block === 'warmup').map((s) => s.round)).size;
  return (
    <>
      <p class="small muted">Warm-up: {warmupRounds} of 2 rounds</p>
      {order.map((id) => {
        const rows = circuit.filter((s) => s.exerciseId === id);
        return (
          <div key={id} class="row small">
            <span>
              {EXERCISES[id].name} · {rows[0].weightKg} kg
            </span>
            <span class="muted">{rows.map((r) => r.repsPerSide).join(' · ')}</span>
          </div>
        );
      })}
    </>
  );
}

function SpinDetail({ s }: { s: SessionRecord }) {
  const sum = s.summary ?? {};
  const avg = sum.avgBpm ?? sum.manualAvgBpm;
  return (
    <>
      <div class="row small">
        <span>Time</span>
        <span>{mmss(sum.durationSec ?? 0)}</span>
      </div>
      <div class="row small">
        <span>Average</span>
        <span>{avg ? `${avg} bpm` : '–'}</span>
      </div>
      {s.kind === 'z2' && sum.zone2Share !== undefined && (
        <div class="row small">
          <span>In zone 2</span>
          <span>
            {mmss(sum.timeInZoneSec ?? 0)} ({Math.round(sum.zone2Share * 100)} %)
          </span>
        </div>
      )}
      {s.kind === 'z5' && sum.intervalPeaks && (
        <>
          <div class="row small">
            <span>Interval peaks</span>
            <span>{sum.intervalPeaks.join(' · ')}</span>
          </div>
          <div class="row small">
            <span>Recovery after 60 s</span>
            <span>{sum.hrRecovery == null ? '–' : `−${sum.hrRecovery} bpm`}</span>
          </div>
        </>
      )}
    </>
  );
}

export function Day({ date }: { date: string }) {
  const d = useData();
  const list = d.sessions.filter((s) => s.plannedDate === date && s.status !== 'in_progress');
  return (
    <main class="screen">
      <Header title={`${dayName(date)} ${shortDate(date)}`} onBack={() => d.go({ name: 'calendar' })} />
      {list.length === 0 && <p class="muted">No sessions on this day.</p>}
      {list.map((s) => (
        <section key={s.id} class="card">
          <div class="row">
            <h2>{KIND_LABEL[s.kind]}</h2>
            <span class="muted small">{statusText(s)}</span>
          </div>
          {s.kind === 'kb' && <KbDetail sets={d.sets.filter((x) => x.sessionId === s.id)} />}
          {(s.kind === 'z2' || s.kind === 'z5') && <SpinDetail s={s} />}
          {s.rating && <p class="small">Felt: {RATING_LABEL[s.rating]}</p>}
          {s.note && <p class="small muted">{s.note}</p>}
        </section>
      ))}
    </main>
  );
}
```

Create `src/ui/screens/Settings.tsx`:

```tsx
import { useState } from 'preact/hooks';
import { describeBackup, exportBackup, importBackup, parseBackup, shareOrDownload, type Backup } from '../../db/backup';
import type { RoundRest, Settings } from '../../model';
import type { TrainingKind, Weekday } from '../../program/types';
import { zone2, zone5 } from '../../program/zones';
import { Header } from '../components/Header';
import { useData } from '../data';
import { KIND_LABEL } from '../format';

const WEEKDAYS = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'];
const BELL_SIZES = [4, 6, 8, 10, 12, 14, 16, 18, 20, 24, 28, 32];
const RESTS: RoundRest[] = [90, 75, 60];
const TRAINING: TrainingKind[] = ['kb', 'z2', 'z5'];

export function SettingsScreen() {
  const d = useData();
  const s = d.settings;
  const [maxHr, setMaxHr] = useState(String(s.maxHr));
  const [maxHrError, setMaxHrError] = useState<string | null>(null);
  const [bellError, setBellError] = useState<string | null>(null);
  const [pending, setPending] = useState<Backup | null>(null);
  const [backupMsg, setBackupMsg] = useState<string | null>(null);
  const [backupError, setBackupError] = useState<string | null>(null);

  const save = (patch: Partial<Settings>) => d.saveSettings({ ...d.settings, ...patch });

  const typed = Number(maxHr);
  const validHr = Number.isInteger(typed) && typed >= 120 && typed <= 230;
  const z2 = zone2(validHr ? typed : s.maxHr);
  const z5 = zone5(validHr ? typed : s.maxHr);
  const saveMaxHr = () => {
    if (!validHr) {
      setMaxHrError('Enter a whole number between 120 and 230.');
      return;
    }
    setMaxHrError(null);
    if (typed !== s.maxHr) void save({ maxHr: typed });
  };

  const toggleBell = (kg: number) => {
    const owned = s.bellsKg.includes(kg);
    if (owned && s.bellsKg.length === 1) {
      setBellError('Keep at least one bell.');
      return;
    }
    setBellError(null);
    void save({ bellsKg: owned ? s.bellsKg.filter((b) => b !== kg) : [...s.bellsKg, kg].sort((a, b) => a - b) });
  };

  const setDay = (day: Weekday, value: string) =>
    void save({ trainingDays: { ...s.trainingDays, [day]: value === 'rest' ? null : (value as TrainingKind) } });

  const exportNow = async () => {
    setBackupError(null);
    setBackupMsg(null);
    try {
      const how = await shareOrDownload(await exportBackup(d.store));
      await save({ lastBackupAt: Date.now() });
      setBackupMsg(how === 'shared' ? 'Backup shared' : 'Backup downloaded');
    } catch (e) {
      if (e instanceof DOMException && e.name === 'AbortError') return;
      setBackupError("Couldn't save the backup. Try again.");
    }
  };

  const pickFile = async (file: File | undefined) => {
    setBackupError(null);
    setBackupMsg(null);
    setPending(null);
    if (!file) return;
    try {
      setPending(parseBackup(await file.text()));
    } catch (e) {
      setBackupError(e instanceof Error ? e.message : String(e));
    }
  };

  const restore = async () => {
    if (!pending) return;
    await importBackup(d.store, pending);
    setMaxHr(String(pending.settings.maxHr));
    setPending(null);
    await d.reload();
    setBackupMsg('Backup restored');
  };

  const forgetStrap = () => {
    d.hr.disconnect();
    void save({ pairedStrapId: undefined });
  };

  const toggleRow = (label: string, checked: boolean, patch: (v: boolean) => Partial<Settings>) => (
    <label class="row">
      <span>{label}</span>
      <input type="checkbox" checked={checked} onChange={(e) => void save(patch(e.currentTarget.checked))} />
    </label>
  );

  return (
    <main class="screen">
      <Header title="Settings" onBack={() => d.go({ name: 'today' })} />

      <section class="card">
        <h2>Heart rate</h2>
        <label class="field">
          <span>Max heart rate</span>
          <input
            inputMode="numeric"
            value={maxHr}
            onInput={(e) => {
              setMaxHr(e.currentTarget.value);
              setMaxHrError(null);
            }}
            onBlur={saveMaxHr}
          />
        </label>
        {maxHrError && <p class="error">{maxHrError}</p>}
        <p class="muted small">
          Zone 2: {z2.low}–{z2.high} bpm · Zone 5: {z5.low}–{z5.high} bpm
        </p>
      </section>

      <section class="card">
        <h2>Training days</h2>
        {WEEKDAYS.map((name, i) => (
          <label key={name} class="row">
            <span>{name}</span>
            <select
              value={s.trainingDays[i as Weekday] ?? 'rest'}
              onChange={(e) => setDay(i as Weekday, e.currentTarget.value)}
            >
              <option value="rest">Rest</option>
              {TRAINING.map((k) => (
                <option key={k} value={k}>
                  {KIND_LABEL[k]}
                </option>
              ))}
            </select>
          </label>
        ))}
      </section>

      <section class="card">
        <h2>Kettlebells you own</h2>
        <div class="chips">
          {BELL_SIZES.map((kg) => (
            <button key={kg} class={s.bellsKg.includes(kg) ? 'chip on' : 'chip'} onClick={() => toggleBell(kg)}>
              {kg} kg
            </button>
          ))}
        </div>
        {bellError && <p class="error">{bellError}</p>}
        <h2>Rest between rounds</h2>
        <div class="chips">
          {RESTS.map((r) => (
            <button key={r} class={s.roundRestSec === r ? 'chip on' : 'chip'} onClick={() => void save({ roundRestSec: r })}>
              {r} s
            </button>
          ))}
        </div>
      </section>

      <section class="card">
        <h2>Cues</h2>
        {toggleRow('Voice', s.voice, (v) => ({ voice: v }))}
        {toggleRow('Beeps', s.beeps, (v) => ({ beeps: v }))}
        {toggleRow('Vibration', s.vibration, (v) => ({ vibration: v }))}
      </section>

      <section class="card">
        <h2>Backup</h2>
        <p class="muted small">
          {s.lastBackupAt ? `Last backup ${new Date(s.lastBackupAt).toLocaleDateString('en-GB')}.` : 'No backup yet.'} Your
          data only lives on this phone.
        </p>
        <button class="btn" onClick={exportNow}>
          Export backup
        </button>
        <label class="btn" style={{ display: 'flex', alignItems: 'center', justifyContent: 'center' }}>
          Import backup
          <input
            type="file"
            accept=".json,application/json"
            style={{ display: 'none' }}
            onChange={(e) => void pickFile(e.currentTarget.files?.[0])}
          />
        </label>
        {pending && (
          <div class="banner">
            <p>Replace all data on this phone with {describeBackup(pending).toLowerCase()}?</p>
            <div class="btn-row">
              <button class="btn" onClick={() => setPending(null)}>
                Cancel
              </button>
              <button class="btn" onClick={restore}>
                Replace all data
              </button>
            </div>
          </div>
        )}
        {backupMsg && <p class="small">{backupMsg}</p>}
        {backupError && <p class="error">{backupError}</p>}
      </section>

      <section class="card">
        <h2>Heart-rate strap</h2>
        <p class="muted small">
          {s.pairedStrapId
            ? 'A strap is paired. It reconnects when you start a ride.'
            : 'No strap paired yet. You pair it at the start of your first ride.'}
        </p>
        {s.pairedStrapId && (
          <button class="btn" onClick={forgetStrap}>
            Forget strap
          </button>
        )}
      </section>
    </main>
  );
}
```
